02 The World Wide Web

Web development begins with structure

Websites support information search, video, shopping, banking, communication, school portals, business, and government services.

Webpage

A single document displayed in a web browser.

Website

A collection of related webpages.

Web browser

Software that reads HTML and displays webpages.

Before building complex web applications, students first learn the language that structures webpage content: HTML.

03 Three basic web technologies

Structure, appearance, and action

HTML

Creates the structure and content. Think of it as the body’s skeleton.

CSS

Controls colors, fonts, spacing, and layout. Think skin and clothes.

JavaScript

Adds behavior and interaction. Think muscles and nerves.

Easy memory guide: HTML = Structure · CSS = Appearance · JavaScript = Action.

04 Core definition

HyperText Markup Language

HTML is the standard markup language used to create and organize the content of webpages.

SOURCE CODEHTML
<h1>Welcome to My Website</h1>
<p>This is my first webpage.</p>
→

Welcome to My Website

This is my first webpage.

HTML describes the structure and meaning of content; it does not normally control the full visual design.

05 Understanding the name

HyperText connects; markup describes

HyperText

Text that connects to another document or webpage through a hyperlink.

<a href="https://www.google.com">Visit Google</a>

Markup language

A language that uses tags to identify and organize content.

<p>Hello, IT students!</p>

Hyperlinks connect webpages and are one of the main ideas behind the World Wide Web.

06 HTML building blocks

Opening tag + content + closing tag

<p>Opening tag starts the element.
HelloContent appears to the user.
</p>Closing tag ends the element.
<p>…</p>Together they form an element.
<img>Some elements have no separate closing tag.
<h1>heading<p>paragraph<a>link<img>image<ul>bullet list<ol>numbered list<li>list item
07 Basic document structure

Every HTML page needs a foundation

index.htmlVALID STRUCTURE
<!DOCTYPE html>
<html>
  <head>
    <title>My First Webpage</title>
  </head>
  <body>
    <h1>Welcome to My Website</h1>
    <p>This is my first HTML webpage.</p>
  </body>
</html>
<!DOCTYPE html>Tells the browser to use modern HTML.
<html>Contains the entire document.
<head>Stores information about the page.
<title>Sets the browser-tab title.
<body>Contains visible page content.
08 Organizing text

Headings create hierarchy; paragraphs carry ideas

Six heading levels

<h1>Information Technology</h1>
<h2>Web Development</h2>
<h3>Introduction to HTML</h3>
… through <h6>

<h1> is the most important heading; lower levels organize sections.

One paragraph, one <p>

<p>My name is Juan Dela Cruz.</p>
<p>I am studying Information Technology.</p>
<p>I want to learn web development.</p>
09 Links and extra information

Attributes add details to an element

<a href="https://www.google.com">Visit Google</a>

Element

<a> creates the hyperlink.

Attribute

href specifies the destination.

Value

The URL is the destination address.

Attributes are normally written inside the opening tag.

10 HTML images

Use <img> to display an image

<img src="laptop.jpg" alt="Laptop Computer" width="300">

src

The source or location of the image.

alt

A short text description for accessibility and failed loads.

width

Controls the displayed width of the image.

If index.html and laptop.jpg are in the same folder, the filename can be used directly. The filename and extension must match exactly.

11 Organizing related information

Unordered and ordered lists

Unordered list — bullets

<ul>
  <li>Keyboard</li>
  <li>Mouse</li>
  <li>Monitor</li>
</ul>
+

Ordered list — numbers

<ol>
  <li>Open Notepad.</li>
  <li>Write the code.</li>
  <li>Save the file.</li>
</ol>

<ul> and <ol> create the list; each <li> creates one list item.

15 Why HTML matters

HTML is a markup language—not a programming language

Programming languages usually include variables, conditions, loops, functions, and calculations. HTML mainly describes how content is structured.

Start

HTML structures content.

Style

CSS adds presentation and layout.

Interact

JavaScript adds behavior and interaction.

HTML supports work with websites, web apps, cloud services, server dashboards, content management systems, and e-commerce.
